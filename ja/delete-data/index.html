データの管理

データの書き出しと削除

ライブラリはあなたのデバイスと、同期を選んだ場合はあなた自身のiCloudにあります。ここでは、コピーを取る方法、1台のデバイスから削除する方法、そしてアカウントとそこに保存されたすべてを削除する方法をご案内します。

どこに何が保存されているか

データ保存場所削除方法
記録、録音、添付ファイル、タスク、メモ、プロジェクト、履歴あなたのデバイス設定 → ローカルデータをすべて削除、またはアカウントを削除（下記）
同期をオンにした場合の、同じライブラリあなた自身のiCloud内のプライベートなデータベース設定 → クラウド同期とAIの設定 → アカウントとライブラリを削除
アカウントID、プラン、同意の選択、利用回数、デバイスの鍵当社のサーバー（Cloudflare）設定 → クラウド同期とAIの設定 → アカウントとライブラリを削除
クラウドAIの結果当社のサーバー（最大24時間）自動的に削除されるほか、その項目を完全に削除したとき、またはアカウントを削除したときに削除されます
月ごとの無料利用回数このデバイスのiOSキーチェーン（数値のみ）毎月リセットされます。アプリを削除した後も、iOSが保持することがあります
サブスクリプションあなたのAppleアカウントAppleでキャンセル（下記）

まずコピーを取る

  1. Second Brainを開き、設定に移動します。
  2. 書き出しを準備をタップし、次にライブラリの書き出しを共有をタップします。
  3. ZIPを「ファイル」に保存するか、好きな場所に送ります。ZIPには、ライブラリ（JSON、Markdown、タスクのCSV）、元のファイル、含められなかったものの一覧が入っています。

このデバイスから削除

1つの項目を削除するには、その項目を削除した後、設定 → 最近削除した項目で完全に削除を使って取り除きます。そうしない場合は、30日後に自動的に削除されます。

このデバイス上のライブラリ全体を削除するには、設定 → ローカルデータをすべて削除を使います。これでアカウント、そのiCloud上のコピー、別のゲストライブラリが削除されることはありません。アプリを削除した場合も、そのデータはデバイスから削除されます。

アカウントを削除

  1. 設定 → クラウド同期とAIの設定を開きます。
  2. アカウントとライブラリを削除をタップして確定します。
  3. Second Brainは、そのアカウントのiCloud上のコピー、そのアカウントについて当社のサーバーが保持するすべてのデータ（セッション、プラン、選択、利用回数、デバイスの鍵、AIの結果）、このデバイス上のそのアカウントのライブラリを削除します。また、「Appleでサインイン」によるアクセスも取り消します。別のゲストライブラリはデバイスに残ります。
サインインの有効期限が切れている場合は、削除を完了するために、同じAppleアカウントでもう一度サインインするよう求められます。デバイスが手元にない場合は、任意のiPhoneまたはiPadにSecond Brainをインストールし、同じAppleアカウントでサインインして、そこから削除してください。

削除後、当社のサーバーに残るのは、内容を含まない目印だけです：削除済みのフラグを付けたハッシュ化アカウントID、その利用回数、購入とデバイスの識別子の一方向ハッシュ。これにより、中断された削除を最後まで完了でき、購入や無料のお試し分が二重に受け取られるのを防げます。ホスティング事業者が保持するデータベースのバックアップは、30日以内に失効します。

サブスクリプション

データ、アカウント、アプリを削除しても、サブスクリプションはキャンセルされません。サブスクリプションはAppleアカウントに属しています。App Storeのサブスクリプション設定でキャンセルしてください。現在の期間が終わるまでは有効なままです。返金はAppleサポートが対応します。

当社へのお問い合わせ

アプリを使えない場合や、データについてご質問がある場合は、topsol.org@gmail.comまでご連絡ください。30日以内にお返事します。当社はアカウントの名前やメールアドレスを保持していないため、アカウントを特定するためにご協力をお願いすることになります。通常、いちばん早いのは、いずれかのデバイスでサインインしてそこから削除する方法です。記録や録音は送らないでください。お手伝いするのに必要ありません。
