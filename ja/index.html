Second Brainのヘルプ

話すか入力するだけで、Second Brainがタスク、イベント、メモ、アイデアに振り分けます。元の内容は残り、どの変更も取り消せます。このページでは、仕組み、必要なもの、お問い合わせ方法をご案内します。

Second Brainの仕組み

頭の中のことを数秒で書き出し、必要なときにまた見つけられます。

マイクをタップして考えるままに話すか、入力します。Second Brainはまず、話したとおりの言葉をそのまま保存するので、何も失われません。そのうえで、中身を提案します。期限付きのタスク、時刻付きのイベント、メモやアイデアを、適切なプロジェクトに振り分けます。何かが作成される前に提案を一つずつ確認でき、どの変更も取り消せます。

  • 記録音声記録は、開いた瞬間に録音を始めます。入力することもできるほか、ほかのアプリからテキスト、リンク、写真、ファイルを共有したり、記録に添付したりできます。
  • スマート入力と確認「完了」をタップすると、スマート入力が日付や時刻を含めたタスク、イベント、メモ、アイデアの下書きを作ります。「作成」をタップする前に、すべての項目を編集できます。確信が持てないものは強調表示されたままになるか、要確認に入ります。
  • ノートに質問するふだんの言葉で質問できます。回答は保存した内容だけから作られ、出典が一覧表示されるので、開いて確かめられます。
  • 「今日」と「カレンダー」期限のもの、次にやること、大切なことがひと目でわかります。タスクとカレンダーAppの予定を並べた週表示もあります。リマインダーと朝のまとめは必要に応じて使えます。
  • 元の内容は、いつも残ります記録した言葉は、そこから作られたものと並んでライブラリに残ります。取り消すを使えばどの整理も元に戻せ、削除した項目は30日間最近削除した項目に残ります。
  • 最初からプライベートデバイスが対応していれば、整理と回答はAppleのオンデバイスモデルによりデバイス上で実行されます。クラウド同期とクラウドAIは、あなたが選ぶまでオフのままです。詳しくはプライバシーをご覧ください。

動作環境

デバイスiOS 18またはiPadOS 18以降を搭載したiPhoneまたはiPad。
オンデバイスAIApple Intelligenceに対応し、iOS 26またはiPadOS 26以降を搭載したデバイスで、Apple Intelligenceがオンになっていて、そのモデルがダウンロード済みであること。ほかのデバイスでも、記録、手動での整理、検索、リマインダーの設定はできます。その場合も、サインインして許可すれば、スマート入力と回答にクラウドのLunaを使えます。
アカウント任意です。記録、整理、検索、書き出し、削除はアカウントなしで使えます。LightやProもアカウントなしで購入できます。iCloudでの同期、Lunaの利用、ページ本文の取り込みには、「Appleでサインイン」が必要です。
インターネット記録、オンデバイスAI、検索、書き出しには不要です。サインイン、購入、iCloud同期、Luna、ページの取り込み、そしてお使いの言語用のAppleの音声ファイルを初めてダウンロードするときに必要です。
アクセス許可音声記録にはマイクと音声認識。カメラや写真は、画像を添付するときだけ。カレンダーは、カレンダーAppを接続する場合だけ。通知は、リマインダーと朝のまとめのためだけに使います。それぞれ、初めて使うときに許可を求められます。
iCloud同期には、十分な空き容量のあるiCloudアカウントが必要です。同期はLightとProに含まれます。
言語英語、ドイツ語、スペイン語、フランス語、日本語、韓国語、ブラジルポルトガル語、簡体字中国語。音声記録はアプリの言語で聞き取ります。設定 → 言語で選べます。

はじめかた

  1. Second Brainを開きます。登録は不要です。最初の瞬間から、ライブラリはあなたのデバイスに保存されます。
  2. マイクをタップして、思いついたことを話します。iOSから求められたら、マイクと音声認識を許可してください。入力でもかまいません。
  3. 「完了」をタップします。スマート入力がタスク、イベント、メモ、アイデアの下書きを作ります。各項目を確認して必要なところを変更し、「作成」をタップします。
  4. ノートに質問します。「サムに何を約束したっけ？」や「歯医者はいつ？」のように質問し、引用された出典を開いて確かめます。
  5. 任意：iCloudで同期したりLunaを使ったりするには、設定 → クラウド同期とAIの設定を開き、Appleでサインインします。それぞれに専用のスイッチがあります。

よくある質問

アカウントは必要ですか？
いいえ。記録、整理、検索、リマインダー、書き出し、削除は、すべてアカウントなしでデバイス上で使えます。アカウントが必要なのは、iCloudでの同期、クラウドでのLunaの利用、ページ本文の取り込みだけです。プランはアカウントなしでも購入できます。サインインしても、既存のゲストライブラリがアップロードされることはありません。アカウントにコピーする考えは、あなたが選びます。
無料で使えるのは何ですか？
テキストでの記録、タスクとプロジェクト、ローカル検索、デバイス上での文字起こし、リマインダー、編集、書き出し、削除は、無料で無制限に使えます。さらに無料プランでは、毎月、音声記録20回、スマート入力40回、ノートに質問するへの質問5回が使えます。回数はデバイスごとに数えられ、毎月1日にリセットされます。保存が妨げられることはありません。上限に達しても、入力して保存することはできます。クラウドAIを許可したサインイン済みのアカウントには、クラウドAI記録10回と回答5回のお試し分が1回だけ付きます。
LightとProでは何が増えますか？
Lightでは、音声記録、スマート入力、「ノートに質問する」の月ごとの制限がなくなり、クイックモードとプライベートなiCloud同期が加わります。また、毎月300回のクラウドAI記録と100回のクラウド回答が含まれます。Proでは、クラウドAI記録が毎月700回、クラウド回答が毎月250回になり、1日1回のクラウド要約と、Webページ本文の取り込みも使えます。Lightは月額で請求されます。Proは月額または年額で、年額プランは対象となる新規登録者なら最初の7日間が無料です。価格はアプリ内とお住まいの国のApp Storeに表示され、請求はAppleが行います。
オンデバイスAIとLunaの違いは何ですか？
オンデバイスAIは、デバイス上で動くAppleのモデルです。書いた内容がデバイスの外に出ることはありません。Lunaは、当社のサーバーを経由して動作するOpenAIのクラウドモデルです。Lunaが使われるのは、サインインしてLunaで整理・回答するをオンにした場合だけで、プランのクラウド利用枠の範囲内に限られます。まずオンデバイスAIが使われ、デバイスで対応できないときにLunaが補います。LightとProでは、設定でLunaをメインのエンジンに選べます。このiPhoneだけに保存をオンにした記録は、どちらのエンジンを選んでもLunaに送られることはありません。
このiPhoneだけに保存をオンにするとどうなりますか？
その記録と、そこから作られたものはすべて、iCloudに同期されることも、クラウドAIに送られることもありません。オンデバイスAIによる整理は引き続き使えます。
回答は信頼できますか？
回答は保存した内容だけから作られ、すべての回答に出典が一覧表示されるので、開いて確かめられます。それでもAIは読み違えたり見落としたりすることがあるため、大切なことに回答を使う前には出典を確認してください。
音声の録音はどうなりますか？
録音はデバイス上で文字起こしされ、文字起こしのためにAppleや当社に送られることはありません。文字起こしが完了すると、この録音を残すをタップしない限り、音声は7日後に削除されます。文字起こしに失敗した場合は、やり直せるよう、削除するまで音声が残ります。音声が削除された後も、文字起こしは残ります。
iPhoneとiPadの間で同期できますか？
はい、LightまたはProで同期できます。両方で同じAppleアカウントを使ってサインインし、ライブラリを同期をオンにします。ライブラリは、当社が読むことのできない、あなた専用のプライベートなiCloudストレージを通じて同期されます。
サブスクリプションが終了するとどうなりますか？
保存したものが削除されることはありません。閲覧、編集、検索、書き出し、削除は引き続き使え、無料プランの月ごとの上限が再び適用されます。同期とクラウドの利用枠は、再び登録するまで停止します。
新しいデバイスで購入を復元するには？
新しいデバイスで、登録したときと同じAppleアカウントを使い、プラン画面で購入を復元をタップします。そのiPhoneでのプランの機能はすぐに使えるようになります。プランをSecond Brainのアカウントに紐づけている場合は、iCloud同期とクラウドの利用枠を取り戻すため、「Appleでサインイン」でもサインインしてください。
自分の言語でアプリを使えますか？
Second Brainは8つの言語に対応し、デバイスの言語に従います。ほかの設定を変えずに別の言語を選ぶには、設定 → 言語を開きます。音声記録もその言語で聞き取るようになります。
データを書き出したり、削除したりするには？
設定 → 書き出しを準備で、元のファイルを含むライブラリ全体のZIPを作成できます。設定 → クラウド同期とAIの設定 → アカウントとライブラリを削除で、アカウント、そのiCloud上のコピー、当社のサーバーが保持するデータが削除されます。詳しくはデータの管理ページをご覧ください。

トラブルシューティング

スマート入力や回答が使えない

  • オンデバイスAIを使うには、Apple Intelligence対応のデバイス、iOS 26以降、iOSの「設定」でApple Intelligenceがオンになっていること、そしてそのモデルのダウンロードが完了していることが必要です。初めてオンにした後、ダウンロードには時間がかかることがあります。
  • お使いのデバイスで実行できない場合は、サインインして設定 → クラウド同期とAIの設定でLunaで整理・回答するをオンにするか、手動で整理を続けてください。どちらの場合も、記録は保存されます。
  • 上限のメッセージが表示された場合は、このデバイスで今月の無料の音声記録、スマート入力、または質問を使い切っています。回数は毎月1日にリセットされ、保存は引き続きできます。

音声記録が文字起こしされない

  • iOSの設定 → Second Brain → マイクと音声認識を確認してください。
  • ある言語を初めて使うときは、Appleの音声ファイルをダウンロードするためにインターネット接続が必要です。
  • 文字起こしに失敗しても録音は保持されるので、やり直すか、自分でテキストを追加できます。

同期が更新されない

  • 同期には、LightまたはPro、サインイン済みのアカウント、そして設定 → クラウド同期とAIの設定でライブラリを同期がオンになっていることが必要です。
  • デバイスがiCloudにサインインしていて、iCloudストレージに空きがあることを確かめてから、今すぐ同期をタップしてください。
  • 同じ項目が2台のデバイスで変更された場合は、どちらのバージョンを残すかをアプリが尋ねます。元の記録は常に保持されます。

リマインダーが届かない

設定で、リマインダー通知がオンかどうかを確認できます。オフになっていた場合は、その行をタップしてiOSの「設定」を開き、許可してください。

プランが認識されない

iPhoneで登録したときと同じAppleアカウントを使っていることを確かめてから、購入を復元をタップしてください。プランをSecond Brainのアカウントに紐づけている場合は、Appleでのサインインも行ってください。返金や請求に関するお問い合わせは、Appleサポートを通じてAppleが対応します。

アプリの言語が違う

設定 → 言語を開き、使いたい言語を選んでください。アプリ、ウィジェット、共有シートがすぐに切り替わります。
